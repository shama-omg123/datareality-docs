# Dashboard Overview

The dashboard is the first screen after login and summarizes activity for the selected product preference.

## Metrics

- Events: count of all reported events in the selected window.
- Serious Injuries: events marked with serious patient outcomes.
- Malfunctions: device malfunction incidents linked to the preference.

## Filtering controls

- By Report Date: filters by the date a record was reported to the authority.
- By Event Date: filters by when the event actually occurred.
- Time window presets: `1 Year`, `6 Months`, or a custom range.
- Region: choose `US` or `EU` to scope metrics.

Use the header controls to switch between date anchors, adjust timeframes, and focus on regional trends.
