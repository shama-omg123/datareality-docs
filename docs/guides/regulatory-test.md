# Running a Regulatory Test

## Process

1. Open the Regulatory Test module from the left menu.
2. Choose the test type (e.g., product batch, device type) and scope.
3. Configure inputs and initiate the run.
4. Monitor progress until completion.

## Outputs

- Pass/Fail status with summary metrics.
- Detailed report with failures, affected lots, and remediation notes.
- Export as PDF/CSV for audit or compliance submissions.
